## 2. 목적

본 프로젝트는 오리온의 K-IFRS 연결재무정보를 영업가치와 주주가치로 전환하는 과정을 재현 가능한 Excel·Python·Marimo 체계로 구현한다. 현재 Phase 1.1의 목적은 가치평가 결과를 개선하는 것이 아니라, 향후 변경의 영향과 책임을 식별할 수 있도록 **현행 모델을 불변 기준선으로 동결**하는 것이다.

본 모델은 교육 및 채용 포트폴리오 목적이며 투자권유, 공정성 의견서, 법정 평가보고서 또는 감사의견이 아니다.

## 3. 범위

### 포함범위

- 한국·중국·기타 국가 매출액 전망
- 매출원가, 판매비, 일반관리비 및 EBIT 전망
- 정상화 현금법인세율을 이용한 NOPAT
- D&A, 유지보수·성장 Capex, NWC 증감을 통한 FCFF
- 자기자본비용, 세후 타인자본비용 및 목표 자본구조를 이용한 WACC
- 추정기간 FCFF 현재가치와 Gordon Growth 계속기업가치
- 기업가치에서 비영업자산, 금융부채, 리스부채 및 비지배지분을 조정한 지분가치
- WACC·영구성장률 민감도 및 사업 시나리오
- Excel–Python 대사, 방향성 검증 및 기준선 회귀 통제

### 현 단계 제외범위

- 경영진 예산·사업계획 및 비공개 Commercial Due Diligence 자료
- 완전한 3개 재무제표 연계모형
- 유사회사 거래배수 및 선행거래 분석
- 독립적인 베타·ERP·국가위험프리미엄 산정
- 리가켐바이오 및 기타 비영업자산의 독립 가치평가
- 세금누수, 처분비용, 유동성 할인 및 지배력 할인
- IFRS 16 처리 대안의 정량 비교
- Mid-year convention 및 정상상태 ROIC·재투자율 fade
- LBO, 인수금융, IRR 및 MOIC

제외범위는 오류가 없다는 의미가 아니라 후속 Phase에서 검증할 항목이라는 의미이다.

## 4. 기준선 성공기준

1. 동일한 원천 커밋과 입력 Excel에서 2026~2030 전망 및 핵심 가치평가 수치가 재현된다.
2. 원천 Excel과 주요 모델 파일의 SHA-256, 크기 및 수정정보가 기록된다.
3. 기준선 JSON은 기계 판독 가능하고 회귀 테스트가 이를 독립적으로 읽는다.
4. 기존 18개 테스트와 신규 기준선 통제가 모두 통과한다.
5. Marimo 정적검사가 오류 없이 통과한다.
6. 현재 알려진 한계는 숨기지 않고 `ISSUES.md` 및 `DATA_GAPS.md`에 기록한다.

## 5. 기준선 변경관리 원칙

- `artifacts/baseline/model_snapshot.json`은 현행 경제적 가정과 계산결과의 증거이다.
- 테스트 실패를 없애기 위해 스냅샷을 자동 갱신해서는 안 된다.
- 기준선 갱신은 다음 조건을 모두 충족해야 한다.
  1. 변경 목적과 근거가 `DECISIONS.md`에 기록됨
  2. 변경 전·후 가치영향이 제시됨
  3. 관련 원천자료 또는 분석가 가정이 식별됨
  4. 검토자가 변경을 의도적 변경으로 승인함
  5. `python scripts/capture_baseline.py --write`를 명시적으로 실행함
- 단순 코드 리팩터링은 기준 결과를 변경해서는 안 된다.

## 7. 재현 절차

```powershell
git clone https://github.com/hahnjune0118/Orion_DCF_Valuation.git
cd Orion_DCF_Valuation
git switch valuation-v2

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt

python scripts\capture_baseline.py
python -m pytest -q
python -m marimo check orion_dashboard.py
```

`capture_baseline.py`를 `--write` 없이 실행하면 현재 스냅샷 후보를 표준출력으로 확인할 수 있다. 기존 기준선을 갱신하려는 의사결정이 승인된 경우에만 `--write`를 사용한다.

## 8. 중요한 시점 해석

가치평가기준일은 2025년 12월 31일이나 정보기준일은 2026년 3월 18일이다. 따라서 본 기준선은 2025년 사업보고서가 공시된 뒤 수행한 **소급적·교육용 가치평가**이다. 2025년 12월 31일 당시 시장참여자가 이용할 수 있었던 정보만 사용하는 contemporaneous valuation으로 해석해서는 안 된다.
