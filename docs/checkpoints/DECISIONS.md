## D-007 — CSV 출처등록부를 권위 있는 메타데이터 원장으로 지정

- 상태: 승인
- 일자: 2026-08-18

## D-011 — 독립 검토 Case를 기준선과 분리된 Challenge Layer로 구현

- 상태: 승인
- 일자: 2026-08-21
- 결정: Management Case는 동결된 기준선 모델을 그대로 사용하고, 감사인 독립검토 Case는 매출성장률·EBIT Margin·WACC·영구성장률의 명시적 조정값으로 별도 산출한다.
- 근거: 경영진 주장과 검토자 판단을 같은 시나리오 집합에 혼합하면 가정의 작성자·책임·검토결론이 불명확해진다.
- 통제: 두 Case의 계산결과와 민감도 중앙값을 자동 대사하며 원본 모델과 입력 매핑을 변경하지 않는다.
- 제한: 독립검토 기본값은 아직 외부 시장자료나 비교기업으로 입증된 감사 판단이 아니므로 교육용 가정 검토 시뮬레이션으로 표시한다.
