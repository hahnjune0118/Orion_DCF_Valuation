# 하드코딩 입력 전수조사

## 1. 조사범위

- Excel: `과거재무제표`, `가정`, `출처`의 값·수식·주석
- Python: `orion_dcf.py`, 계산 모듈 5개, `orion_dashboard.py`, `orion_valuation_lab.py`
- 분류: `공시값`, `시장자료`, `계산값`, `분석가 가정`
- 원칙: 출처가 없으면 값을 보정하거나 새로 만들지 않고 DATA_GAPS에 연결한다.

## 3. 결론

- 공시값과 계산값은 공시 페이지, Excel 셀, Python 산식까지 추적된다.
- 경제적 결론에 큰 영향을 주는 WACC·성장률·마진·재투자·운전자본 가정은 외부 검증 전이며 낮은 신뢰도로 표시했다.
- 동일 주가와 서로 다른 시나리오 조정폭이 복수 파일에 존재한다. 현재 값은 기준선 보존을 위해 변경하지 않았고 중앙 집중화는 후속 작업으로 남긴다.
